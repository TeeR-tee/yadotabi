# NEXT — R142 固有名を持たない一般名詞だけの候補を落とす(R116)

- タスクID: **R142**(ROADMAP の R116 を実測のうえ実装する)
- 難易度: 中(除外ルール1本の追加。ただし**挿入位置を間違えると1件も落ちない**)
- 所要目安: 40〜60分

## 目的

宿の客が「商店街」というカードを見ても、どの商店街なのか分からない。
`dump-rank dogo` の **16位が `商店街`(osm単独・宿から30m・カテゴリ「観光名所」・要約×画像×公式×)**で、
これは R139/R140 で詰めた bare カード(情報ゼロの35枚)の1枚でもある。
**名前そのものが一般名詞**なので、どれだけ表示を工夫しても伝わる情報が増えない
(R136 営業時間・R137 公式ドメイン・R139/R140 面積の3サイクルで「出せるものは出し切った」あとに残った、
出し方ではなく**候補そのものが悪い**類の問題)。

### 2. 誤爆リスクは「完全一致」にすれば消える(R116 が前回見送った点の再検証)

R116 は「誤爆リスクが高い」として見送られていたが、**部分一致でやろうとしたのが原因**。
今回は**完全一致(`=== `)のみ**にすることで、実測で誤爆0を確認済み:

- 4エリアの OSM 名で長さ4文字以下のものを全件列挙して突き合わせた結果、
  **`湯畑`・`筆塚`・`大湯`・`祠`・`地蔵`・`拝殿`・`本殿`・`鐘`・`襷`・`定礎`** のような短い名前は
  下の候補リストのどれとも一致しない(完全一致なので巻き込まれない)。
- 逆に **`〇〇商店街`・`道後ﾊｲｶﾗ通り`・`西の河原公園`・`地蔵の湯まえ足湯`・`湯けむり亭`** のように
  固有名が付いているものは、完全一致しないので**全て残る**。

### 3. おまけの実測: 動物の種名が「動物園」カテゴリで5件出ている(kusatsu)

`fixtures/kusatsu.json` に `{"name":"カピバラ","tourism":"zoo"}`・`ニホンザル`・`ウサギ`・`ラマ、ヤギ、ヒツジ`・`爬虫類` の
**5件**があり、うち **`ドクターフィッシュ` は kusatsu 上位30枚の22位に出ている**(more 側には ニホンザル4位・ウサギ14位・ラマ、ヤギ、ヒツジ22位・カピバラ30位)。
これらは草津熱帯圏(2位に既に居る)の**中の展示**であって独立した行き先ではない。
ただし **これは今回のタスクの範囲外**とする(理由は「却下した案」の(d)を参照)。

### 4. **最重要の実装上の罠**: 挿入位置を間違えると1件も落ちない

`assets/engine.js:637 isExcludedName()` は **冒頭で `if (isProtectedName(t)) return false;`** している。
そして `NAME_PROTECT_SUFFIX`(`assets/engine.js:141-151`)には **`足湯`・`記念碑`・`公園`・`庭園` が入っている**。
したがって今回落としたい11件のうち **`足湯`×6 と `記念碑`×2 は保護リストに直撃して先に return false される**。
**R141 とまったく同じ罠**(NIGHTLOG R141 に「保護リストに直撃して判定に届かなかった」と記録がある)。
→ **新ルールは `isProtectedName` の呼び出しより前に置くこと。**

## 実装方針

1. `engine.js` に定数を1つ追加する(名前は `GENERIC_NAME_NG` 等)。**完全一致で当てる配列**で、中身は実測で当たった語+明らかな同類のみ:
   `商店街`, `足湯`, `記念碑`, `国登録記念物`, `公園`, `庭園`, `展望台`, `駐車場`, `トイレ`, `広場`, `売店`, `休憩所`, `石碑`, `碑`, `鳥居`, `史跡`, `古墳`, `温泉`, `神社`, `寺`, `滝`, `池`, `橋`, `山`, `川`
   (**当たらない語を足すのは構わないが、2文字以上の一般名詞に限ること。`湯`・`泉`・`塚`・`岳` のような1文字は絶対に入れない** — 短い固有名と衝突しうる)
2. `isExcludedName()` の **`isProtectedName` より前**に、`stripDisambiguation` 後の文字列が上記配列と**完全一致**したら `return true` を入れる。
   なぜ保護より前なのかを**コードコメントに R141 の前例つきで書く**(次に読む人が同じ罠を踏まないため)。
3. 4エリアで `dump-rank` の before/after を取り、**dogo 以外の3エリアが完全無差分**であること、dogo は 1枚だけ消えて1枚繰り上がることを目視する。
4. `check-engine.mjs` に `(r142)` 節を追加。**落とすケース**(`商店街`・`足湯`・`記念碑`・`国登録記念物`)と、**残す対照**(`湯畑`・`筆塚`・`道後ﾊｲｶﾗ通り`・`西の河原公園`・`地蔵の湯まえ足湯`・`別府公園`・`道後公園` あたり)を必ず両方入れる。

## 却下した案とその理由

- **(a) 部分一致にする案** → R116 が「誤爆リスクが高い」と見送った当のもの。`商店街` を部分一致にすると `〇〇商店街` まで落ちる。**完全一致以外は採らない**。
- **(b) 文字数で切る案(「3文字以下は落とす」等)** → 実測で `湯畑`(kusatsu 20位・草津の象徴)・`筆塚`(19位)・`大湯`・`椿園` が全滅する。即却下。
- **(c) `NAME_PROTECT_SUFFIX` から `足湯`・`記念碑` を外す案** → `地蔵の湯まえ足湯`・`油屋熊八の像`周辺の記念碑系など、**固有名を持つ正当な候補**まで保護が外れて `TITLE_*_NG` に当たりうる。保護リストは触らず、その前に完全一致ルールを置く。
- **(d) 動物の種名(カピバラ等)も同時に落とす案** → 落とす根拠が「名前が一般名詞」ではなく「`tourism=zoo` なのに施設ではなく展示である」という**別の軸**で、kusatsu 上位30枚の22位「ドクターフィッシュ」が消えて繰り上がりが起きる=**影響範囲が今回の1枚から広がる**。1サイクル1タスクの原則に従い、**今回は実装せず ROADMAP に新規項目 R143 として起票するだけ**にする。
- **(e) R103(応答時間の「遅い」印)を選ぶ案** → 計画役が `node docs/check.mjs` を実行して実測したところ **合計29件 / 総計 3750ms / 平均 129ms / 最遅 `index.html` 231ms**。最遅でも**平均の 1.79倍**で、R116 の提案する「平均の2倍」というしきい値は**今日の実測では1件も発火しない**(印が1つも出ない機能になる)。しかも出力先は GitHub Actions のログで**実ユーザーには一切見えない**。優先度は最下位。
- **(f) R102(撮影一覧スクリプト)を選ぶ案** → R92 で保持方針・`archive-shots.mjs`・CHECKS.md への追記が済んでおり、残るのは枚数集計の表示だけ。**開発者向けで実ユーザー影響ゼロ**。ROADMAP にも「必要になったら着手」と補記済み。
- **(g) R85(英語版デモページ)を選ぶ案** → 営業先は国内の宿を想定しており、英訳1枚の需要が今あるかは**みのるんの判断**が要る(AUTOPILOT 絶対ルール2「判断を必要とする作業は選ばない」に抵触)。
