- **本番確認は必ず実ブラウザで**(curl や素の fetch は Overpass に406で弾かれ誤診断になる)。**`geo.js` は10分間キャッシュされる**。
- **数字を報告するときは必ず測定条件を添える**(どのエリアか/固定データか本番か/初見かキャッシュありか)。
