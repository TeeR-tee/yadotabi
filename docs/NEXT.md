本項では、かつて別府駅商業施設（べっぷえきしょうぎょうしせつ）と総称されていた、

問題は2つ重なっている:
- **索引記事**である(`本項では…以下の…について述べる` = 複数対象をまとめた記事。座標を1つ持たせて「宿から982m・徒歩◯分」と出すこと自体が誤り)。
- **`かつて…と総称されていた`** = 現在は誰も使わない呼び名が、要約と写真つきでカードの見出しになっている。

既存3軸のどれにも当たらないことを確認済み:
- R119/R120 の「かつて」軸は `definitionPredicate()`(**述部**)を見る。この `かつて` は**主題部**にあるので当たらない。
- R132 の `DEFINITION_NOT_PLACE`(`戦いである`/`合戦である`)にも当たらない。
- `TITLE_KEYWORD_NG` にも当たらない(`商業施設` は正当な地物名にも出うるので入れてはいけない)。

### (2) 採用するルールの精度(4エリア200記事で計画役が実測済み)

判定: **`extract` の先頭が `本項では` で始まる**

- ヒット: **1件のみ**(beppu 別府駅商業施設)
- 誤爆: **0件**(kusatsu 50 / hakone 50 / dogo 50 / beppu 50 = 計200記事)

理由: `本項では` は Wikipedia の索引記事・曖昧さ回避まわりの定型句で、単一の地物記事は必ず「〇〇（よみ）は、…」と記事名の言い直しから始まるため構造的に当たらない。

**`について述べる` 単体は絶対に入れないこと。** 将来「〇〇の由来について述べる」のような地物記事本文に当たりうるため、必ず**冒頭一致(`^本項では`)**の形で持つ。
