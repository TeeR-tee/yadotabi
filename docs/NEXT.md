## 目的

オーナー指摘「**歴史に興味のない人にも同じものを出すのはナンセンス**」への回答。
市場調査役は「宿の性格から興味を推測する」案を**やるべきでないと結論**した(`計画書一式/10_市場調査_競合分析と提案軸.md` 末尾節)。理由は ①宿の属性と客層の対応は統計的に崩れている(「ビジネスホテル=出張」ですら不成立) ②旅行目的は温泉・自然・歴史・グルメが各3〜4割で重複し「歴史好き/興味なし」の二分が実態と合わない ③入力ゼロで推測する事例は全て行動ログを持ち、ログゼロのやどたびには移植不可 ④**やどたびは理由を書くので、推測を外すと即座に嘘として露見する**(42%が個別化を「的外れ・気持ち悪い」と回答)。

**採るのは代案③「束にラベルを付けて、選択を利用者に返す」**。推測せず、**選べるようにする**。歴史好きは「歴史を歩く」の束を読み、興味のない人はその束ごと読み飛ばす。何も聞いていないので**入力ゼロを一切破らない**。

## 実装方針(**今回やる範囲 = 段階1のみ**)

1. `engine.js` に `THEME_OF`(上表(C))と `THEME_ORDER_LABELS` を定数として置く。
2. `engine.js` に純関数 `bundle(cards)` を追加し `global.YadoEngine.bundle` で公開する。仕様:
   - 入力はカード配列。各カードの `_debug.category` を `THEME_OF` で引く。表に無ければ `'この土地の名物'`。
   - **カードの順序は絶対に変えない。** 返すのは `[{label, indices:[...]}]` の配列で、**元配列の添字だけ**を持つ。
   - 束の並びは「その束に含まれる**最小の添字**の昇順」= 上位カードを持つ束が上。
   - **1件しかない束は生成せず、その添字を `'この土地の名物'` 束へ寄せる**(実測ではゼロだが、他エリアの保険)。寄せた結果 `'この土地の名物'` も1件なら、その束だけラベル無しで出す(見出しを出さない)。
3. `app.js` の `renderFeed()`:
   - `state.cards.concat(state.moreOpen ? state.more : [])` を `bundle()` に掛け、**カードを1枚も並べ替えずに**、束の切れ目に `<h2 class="feedbundle">歴史を歩く <span>3件</span></h2>` を差し込む。
   - **重要**: 現状は `state.cards.map(cardHtml)` の連結なので、**`cardHtml(card, index)` の `index` は今のまま**(`data-index` と番号バッジの番号)にしたうえで、束見出しだけを間に挟む。**並べ替えではなく見出しの挿入**。
4. `ui.css` に `.feedbundle` を足す。既存カードのスタイルには触らない。

## 実装上の罠

1. **`data-index` と番号バッジは `state.cards`/`state.more` の添字に直結している**(`app.js:1028` `data-no`、`app.js:2063-2066` `feedcard__no` のクリック、`app.js:2109` `state.cards[Number(article.dataset.index)]`、`app.js:1466` の `feedSpotMarkers`)。**カードを1枚でも並べ替えると地図のピン番号とカードの番号がずれる。** 束は**見出しの挿入だけ**で、配列の順序は絶対に触らない。
2. `app.js:2092` の `linkedCard = state.cards[Number(art.dataset.index)]` は `state.cards` しか見ていない。展開後の `more` カードは `index >= state.cards.length` を持つので、**見出しを挟んでも既存のこの分岐の挙動を変えてはいけない**。
3. `observeCards()`(`app.js:1302`)は `.feedcard[data-index]` を拾う。**見出しに `data-index` を付けない**こと(拾われて passive log が壊れる)。
4. `_debug` は常に付いている(`engine.js:1548`)が `toCard()` 経由のカードにしか乗らない。`card._debug` が null なら `'この土地の名物'` に落とす。**例外を投げない。**
5. カード名は既に `<h2>`(`app.js:1038`)。束見出しを `<h2>` にすると見出し階層が壊れるので **`<h3 class="feedbundle">`** を使い、`check-a11y.mjs` の結果を必ず確認する。
6. `renderFeed()` は段階描画で複数回走る(osm→wiki→done)。**`loading` 中は束見出しを出さない**(スケルトンと混ざる)。
