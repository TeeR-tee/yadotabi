# やどたび (v1)

ホテル名を入れるだけで、「このホテルに泊まる人の定番」「発見」「時間枠プラン」「近そうで行けない」を1画面で提案するスマホファーストの静的Webアプリです。行った先は「行った!」ボタンでその場で記録できます。

## 起動方法

1. `start-server.bat` をダブルクリックする
2. 自動でブラウザが開き、`http://localhost:3000` が表示される
   (開かない場合は手動でブラウザを開いてこのURLにアクセスしてください)

※ 初回はNode.jsのパッケージ `serve` を一時的にダウンロードするため、少し時間がかかることがあります。

## 使い方

1. ホテル名または住所を入力し、泊数と移動手段(徒歩/公共交通/車)を選ぶ
2. 「プランを見る」をタップする(候補が複数出たら、目的のホテルをタップして選ぶ)
3. 地図とおすすめプランが表示される。カードの「Googleマップで見る」から実際のルートも確認できる
4. 気に入ったスポットは「行った!」ボタンでその端末に記録できる

## 仕組み(かんたん解説)

- **ホテル検索・住所→緯度経度変換**: [Nominatim](https://nominatim.org/)(OpenStreetMapの無料ジオコーディングサービス)を使っています。
- **周辺の観光スポット取得**: [Overpass API](https://overpass-api.de/)(OpenStreetMapのデータを検索できるサービス)を使って、ホテル周辺の観光地・施設情報を集めています。
- **人気度(「定番」か「発見」かの判定)**: [Wikidata](https://www.wikidata.org/)の sitelinks 数(その項目が何言語のWikipediaに載っているか)と、日本語版Wikipediaの月間閲覧数を組み合わせて算出しています。どちらも無料のAPIです。地方の温泉地などで絶対的な閾値に誰も届かない場合は、その土地の中で相対的に目立つスポットを「定番」に繰り上げるロジックも入っています。
- **プラン作成**: AIではなく、距離や移動手段をもとにした「ルールベース」のロジックでスポットを振り分け、初日午後・2日目午前などのプラン枠に組み立てています。
- **地図表示**: [Leaflet](https://leafletjs.com/)というライブラリと、OpenStreetMapの地図タイルを使っています。
- **記録の保存**: 「行った!」の記録は、サーバーには送らず、ブラウザの `localStorage`(その端末の中だけ)に保存しています。検索結果のキャッシュも同様に端末内の `localStorage` に保存し、同じホテルを再検索したときのAPI呼び出しを減らしています。

すべて無料のオープンデータ・サービスを使っており、npm installやビルドは不要です。ブラウザで `index.html` を開くだけで動く素のHTML/CSS/JavaScriptで作られています。

## 無料APIのマナー

このアプリは無料の公共APIに支えられています。使いすぎるとサービス側に迷惑がかかり、最悪アクセス禁止(BAN)になるので、次のマナーを守って使ってください。

- **Nominatim**: 1リクエスト/秒を超えないこと(連続検索を高速で繰り返さない)。
- **Overpass API**: 広い範囲や複雑すぎるクエリ(重いクエリ)を投げないこと。
- **OSM地図タイル**: 大量アクセス・自動巡回はしないこと。
- 同僚やもっと多くの人に使ってもらってアクセス数が増えてきたら、地図タイルなどを商用サービス(有料)に切り替えることを検討してください。

## GitHub Pages 公開手順(初心者向け)

同僚に触ってもらうために、無料でWeb公開できる「GitHub Pages」を使います。PowerShellで以下を実行してください。

1. GitHubで空のリポジトリ `yadotabi` を作成する(READMEなどは追加しない「Empty repository」で作成)
2. このフォルダでリモートを設定してpushする

   ```powershell
   git remote add origin https://github.com/<あなたのGitHubユーザー名>/yadotabi.git
   git push -u origin main
   ```

3. GitHubのリポジトリページで `Settings` > `Pages` を開く
4. `Source` を `Deploy from a branch` にし、ブランチを `main` / フォルダを `(root)` にして `Save`
5. 数分待つと `https://<あなたのGitHubユーザー名>.github.io/yadotabi/` でアクセスできるようになる

### 更新するとき

コードを直したら、次の2つのコマンドだけでOKです。

```powershell
git add -A
git commit -m "変更内容を1行で"
git push
```

### 同僚に共有するときの注意

「行った!」の記録や検索キャッシュは各自の端末の `localStorage` にしか保存されません。同僚に公開URLを共有しても、あなたの記録が見えたり、記録がみんなで共有されたりすることはありません(それぞれの端末で個別に記録されます)。
