このお宿のまわり(やどたび)

宿の周辺スポットをやどたびが自動で提案します。宿ページに1行埋め込むだけで表示できます。

  • 1行の iframe タグを貼るだけで設置できます。
  • 宿の位置情報から周辺スポットを自動生成、手入力は一切不要です。
  • APIキー不要・利用料無料でご利用いただけます。
  • &bg=fff7e6 で背景色を宿ページに合わせられます(6桁の16進のみ)。ただし相対輝度0.5未満の暗い色は文字が読めなくなるため自動的に既定色に戻ります(黒や濃紺などの暗色は指定できません)。
  • iframe は独立した文書なので、宿ページ側のCSS・JavaScriptからは干渉されません(逆にやどたび側も宿ページを書き換えません)。
  • sandbox は貼り先とやどたびが別オリジンのときに効く保護です。同じオリジンに置くと allow-same-origin により実質無効になります(無害ですが保護にもなりません)。
<iframe src="https://teer-tee.github.io/yadotabi/?hotel=36.6226,138.5960,草津 湯けむり荘&embed=1&bg=fff7e6" width="100%" height="720" style="border:0;border-radius:10px;" sandbox="allow-scripts allow-same-origin allow-popups allow-popups-to-escape-sandbox" referrerpolicy="no-referrer"></iframe>

・width / height は初期値(720程度)のままで構いません。下記の受信スクリプトを一緒に設置すると、中身の高さに合わせて自動で伸びます(設置しない場合は固定高のままになり、宿の紹介が長いと中に二重スクロールが出ます)。
・?hotel= の宿名部分は日本語や空白を含むため、URLエンコードが必要です(例: 「草津 湯けむり荘」→ %E8%8D%89%E6%B4%A5%20%E6%B9%AF%E3%81%91%E3%82%80%E3%82%8A%E8%8D%98)。
・受信スクリプトの実物はこのページの </body> 直前(下記)にあります。このページのソースをそのままコピーしてお使いいただけます。
・受信スクリプトは 60000px を超える高さは無視します(異常値で親ページが壊れるのを防ぐため)。 

<script>
window.addEventListener('message', function (e) {
  if (e.origin !== 'https://teer-tee.github.io' && e.origin !== location.origin) return;
  var data = e.data;
  if (!data || typeof data !== 'object' || data.type !== 'yadotabi:height') return;
  var height = data.height;
  // 上限60000px: 実測の最大は kusatsu desktop の60枚展開後で34075px(2026-09-16)。その約1.8倍を保険の上限にする。
  if (typeof height !== 'number' || !isFinite(height) || height < 100 || height > 60000) return;
  var iframe = document.querySelector('iframe.embed');
  if (!iframe) return;
  iframe.style.height = height + 'px';
});
</script>
