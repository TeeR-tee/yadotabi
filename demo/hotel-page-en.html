Around this hotel (Yadotabi)

Yadotabi automatically suggests nearby spots around the hotel. Just embed one line on your hotel page to display it.

Note: the embedded widget itself is currently Japanese-only.

  • Just paste a single iframe tag to install it.
  • Nearby spots are generated automatically from the hotel's location - no manual input required.
  • No API key required, and free to use.
  • Use &bg=fff7e6 to match the background color to your hotel page (6-digit hex only). Dark colors with relative luminance below 0.5 will automatically fall back to the default color since text would become unreadable (colors like black or dark navy cannot be specified).
  • The iframe is an independent document, so it is not affected by your hotel page's CSS/JavaScript (and Yadotabi does not modify your hotel page either).
  • sandbox is a protection that applies when the embedding page and Yadotabi are on different origins. If placed on the same origin, allow-same-origin effectively disables it (harmless, but no longer a protection).
<iframe src="https://teer-tee.github.io/yadotabi/?hotel=36.6226,138.5960,Kusatsu Yukemuri Sou&embed=1&bg=fff7e6" width="100%" height="720" style="border:0;border-radius:10px;" sandbox="allow-scripts allow-same-origin allow-popups allow-popups-to-escape-sandbox" referrerpolicy="no-referrer"></iframe>

· The width / height can stay at their initial values (around 720). If you also install the receiver script below, the frame will automatically grow to match the content height (without it, the height stays fixed, and a long hotel description will cause a double scrollbar inside).
· The hotel name part of ?hotel= must be URL-encoded if it contains non-ASCII characters or spaces.
· The actual receiver script is included on this page just before </body> (shown below). You can copy this page's source as-is.
· The receiver script ignores any height value above 60000px (to prevent an abnormal value from breaking the parent page). 

<script>
window.addEventListener('message', function (e) {
  if (e.origin !== 'https://teer-tee.github.io' && e.origin !== location.origin) return;
  var data = e.data;
  if (!data || typeof data !== 'object' || data.type !== 'yadotabi:height') return;
  var height = data.height;
  // Upper limit 60000px: the measured max is 34075px after expanding all 60 cards on kusatsu desktop (2026-09-16). This is roughly 1.8x that, as a safety margin.
  if (typeof height !== 'number' || !isFinite(height) || height < 100 || height > 60000) return;
  var iframe = document.querySelector('iframe.embed');
  if (!iframe) return;
  iframe.style.height = height + 'px';
});
</script>
